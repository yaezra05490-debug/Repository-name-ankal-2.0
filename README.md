# אנק״ל 2.0

מערכת עברית לניהול, ניקוי והמרת אנשי קשר. האתר מיועד ל־Netlify, שרת הנתונים הוא Google Apps Script, והמידע המקוון נשמר ב־Google Drive של המנהל.

## מבנה הפרויקט

- `src/` — האתר.
- `src/dedupe.js` — מנוע איתור הכפולים והסימונים. קוד טהור בלי DOM, ולכן נבדק אוטומטית.
- `src/YAEZRA/` — אתר הניהול. עמוד יחיד ועצמאי, מוגש מאותו דומיין בכתובת סודית.
- `netlify/functions/ankal-api.mjs` — החיבור בין האתר ל־Apps Script.
- `apps-script/` — קוד השרת.
- `main.js`, `preload.js` — תוכנת Windows.
- `scripts/release.ps1` — מעלה את קובץ ההתקנה ל־GitHub Releases.
- `node/` — Node נייד. מאפשר להריץ בדיקות ובנייה בלי להתקין כלום (לא נכנס ל־git).
- `ADMIN_SETUP_GUIDE_HE.md` — מדריך הקמה מלא למנהל.
- `USER_GUIDE_HE.md` — מדריך למשתמשים.

## כתובת Apps Script

מומלץ להגדיר ב־Netlify משתנה סביבה `APPS_SCRIPT_URL`. לחלופין פותחים רק את `netlify/functions/ankal-api.mjs` ומחליפים את `PASTE_APPS_SCRIPT_URL_HERE` בכתובת `/exec`.

## בדיקה ובנייה

הדרך הקצרה בלי להתקין כלום — הקבצים בשורש הפרויקט:

- `בדיקות.cmd` — מריץ את כל הבדיקות.
- `הרצה.cmd` — מפעיל את התוכנה (בהרצה ראשונה מתקין תלויות, דורש אינטרנט).

או מהטרמינל:

```bash
npm test          # בדיקות: VCF, מנוע הכפולים, חיווט הממשק
npm run smoke     # בדיקת עשן: מריצה את האתר בדפדפן ועוברת על האשף מקצה לקצה
npm install
npm run build
```

בניית Windows נעצרת אם הבדיקות נכשלות.

### שחרור גרסה למשתמשים

```powershell
npm run build            # יוצר dist/ankal-windows.exe  (כ־92MB)
.\scripts\release.ps1    # מעלה ל־GitHub Releases
```

הכפתור באתר מצביע ל־`releases/latest/download/ankal-windows.exe` — כתובת יציבה
שמפנה תמיד למהדורה האחרונה, ולכן אין מה לעדכן בקוד בשחרור גרסה.
דורש פעם אחת: `winget install GitHub.cli` ואז `gh auth login`.

הקובץ אינו נשמר במאגר בכוונה: 92MB היו מנפחים כל שכפול וכל דיפלוי ל־Netlify.

### שתי מלכודות בבנייה, שכבר מטופלות

- **`productName` חייב להישאר באנגלית.** electron-builder מחשב את גודל הקבצים
  ב־asar לפי מספר תווים ולא לפי בתים. שם בעברית (שני בתים לתו) גרם ל־package.json
  הפנימי להיחתך באמצע, ל־JSON לא תקין, והתוכנה פשוט לא נפתחה בלי שום הודעת שגיאה.
  כותרת החלון בעברית מוגדרת ב־`main.js`, ואינה תלויה בשדה הזה.
- **`signAndEditExecutable: false`.** ערכת כלי החתימה של electron-builder דורשת
  יצירת קישורים סימבוליים, שנכשלת ב־Windows בלי Developer Mode. הכלים האלה נחוצים
  רק לחתימה דיגיטלית ולעריכת מטא־דאטה, והתוכנה ממילא אינה חתומה.

## אתר הניהול

`src/YAEZRA/index.html` — עמוד יחיד שמראה משתמשים, את הרשימות של כל אחד, את אנשי
הקשר בכל רשימה, ומאפשר ייצוא ל־VCF, CSV ו־Excel.

שתי שכבות הגנה:

1. **כתובת סודית.** הנתיב מוגדר ב־`netlify.toml`, והנתיב הגלוי `/YAEZRA/` חסום
   ומחזיר 404. להחלפת הכתובת משנים שורה אחת בקובץ.
2. **הרשאת מנהל בשרת.** כל בקשה עוברת דרך `requireAdmin_` ב־Apps Script, שמשווה
   מול `ADMIN_EMAIL` שבמאפייני הסקריפט. זו ההגנה האמיתית: גם מי שיגלה את הכתובת
   לא יראה שום נתון.

## מנוע הכפולים

הלוגיקה יושבת ב־`src/dedupe.js` בלבד, ו־`app.js` רק קורא לה. כך אפשר לבדוק אותה
בלי דפדפן — `tests/dedupe.test.js` מכסה כל התנהגות שיש עליה החלטה: נרמול מספרים,
דמיון שמות, סיווג קבוצות, ושיוך מספר למשבצת הנכונה.

שני קבועים שולטים ברגישות ואפשר לכוון אותם:

- `FUZZY_NAME_MIN_SIMILARITY` (0.85) — כמה שני שמות צריכים להיות דומים כדי להיחשב קשורים.
- `CROWD` (6) — מאיזו שכיחות ערך מפסיק להיות מזהה. מספר שיושב על 6 כרטיסים ומעלה
  נחשב מרכזייה, ושם שחוזר 6 פעמים ומעלה נחשב שם ממלא־מקום. בשני המקרים הערך
  לבדו כבר לא מקשר, וצריך אות נוסף.
